# Architecture Decision Records (ADR)

本文档目录包含了 HertaBase 项目的所有架构决策记录（Architecture Decision Records）。

架构决策记录是一种用于捕获重大架构决策及其背景、动机和后果的简短文本文档。我们在项目推进过程中，会使用 ADR 来记录关键的技术选型和设计考量。

- [ADR-002: 采用 rquickjs 作为 JS 扩展运行时](002-js-runtime-rquickjs.md)
- [ADR-003: 采用 Salvo 作为 Web 框架](003-web-framework-salvo.md)
